# 钱包发现与选择测试

当前支持 EIP-6963 多钱包发现、旧式 `window.ethereum` 兼容入口和本页选择；尚不建立 Session，也不请求账户、切链、签名或发送交易。实现及验证状态见[迭代 2 plan](iterations/02-connection-session/plan.md)。

## 本地预览

前置条件：按 [README](../README.md#环境准备)安装工具并执行 `npm ci --prefix web`。以下命令在仓库根目录运行，无需启动或停止本地 Bridge 服务：

```sh
npm --prefix web run dev
```

在目标 Chrome 配置中访问终端显示的 Local 地址，通常为 `http://127.0.0.1:5173/`；以实际输出为准。应显示「开发预览」和「选择浏览器钱包」。结束时在启动终端按 `Ctrl+C`，不产生钱包或服务数据。

无扩展时显示未发现说明。安装并允许访问页面的钱包可通过标准公告加入列表，不按品牌筛选；旧式入口显示兼容名称，无法保证枚举所有旧式扩展。点击单选项后显示当前选择；「重新检测钱包」、迟到公告及窗口聚焦不改变选择，刷新页面后需重新选择。标准信息补齐时，已选旧式实例保持选中。

钱包名称、来源与图标由扩展提供，不代表身份认证。发现或选择均不应出现钱包授权／交易弹窗；预览不调用服务 API，不表示已建立连接。正式内嵌页面在[浏览器授权](browser-testing.md#手动验证授权页面)后显示同一面板；已有服务不会随前端构建自动升级。

## 自动测试

已安装 Google Chrome 时执行：

```sh
npm --prefix web run test:wallet:chrome
```

使用 Playwright Chromium（CI 同此）：

```sh
npm --prefix web run browser:install
npm --prefix web run test:wallet
```

预期 9 项测试通过、退出码为 0，覆盖多钱包、迟到／重复／冲突公告、旧式升级、异常数据、图标与文本、生命周期、无自动钱包调用及窄屏。测试自动启动并停止 `127.0.0.1:4173` 的 Vite；该端口须空闲，遇到占用会失败，不复用或停止其他进程。使用隔离浏览器上下文与模拟 Provider，不访问正式 Chrome 配置、服务端口或凭据。

类型与生产构建可执行 `npm --prefix web run build`；测试结束后无服务数据需要清理，浏览器测试报告写入已忽略的 `web/test-results/`。授权页面的组合测试仍使用独立程序及固定端口，步骤见[浏览器测试指南](browser-testing.md#自动浏览器测试)。
