# 决策记录

记录重要结论与取舍。产品行为见[需求基线](requirements.md)，开发顺序见[路线图](roadmap.md)；未决问题放当轮 spec，尚未启动的迭代问题放路线图。

## 记录规则

- 用户确认：明确记录用户选择、日期、适用范围；如替代旧结论，标明替代关系。
- 技术决定：已授权范围内的实现选择，记录理由和验证；不代表用户确认了新的产品行为。
- 已替代：保留原结论与被替代原因，方便追溯。

较复杂的技术决策可单独建立 ADR 并从此处链接；当前先维护本表，避免空白模板堆积。
