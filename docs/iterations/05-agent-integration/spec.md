# 迭代 5 · AI agent 接入

首批验收 Codex 与同机运行的 Bridge。通过 MCP 交付连接、Session 管理、单笔交易与请求查询／取消。钱包审批沿用现有浏览器页面。[首版范围](../../requirements.md#2-面向的-client-与交付方式) · [验收项 A-18](../../acceptance.md)

## 首次连接

1. 用户在 Codex 指定目标网络。首次钱包工具调用时接入本地服务，创建连接请求并立即返回请求 ID、原审批链接和到期时间。
2. Codex 先向用户展示可点击的链接。用户在已授权浏览器中核对钱包、账户和网络，点击「同意连接」。首次使用的浏览器按[授权指南](../../local-credentials.md)完成授权后再打开原链接。
3. Codex 任务仍运行时，优先自动查询原连接。成功后展示固定账户和网络，并取得后续交易所需的 Session ID。若请求已拒绝、取消或到期，展示服务记录的结果并结束等待。
4. 用户结束本轮对话或中断等待后，可以回到同一对话说「继续」。Codex 从上下文取回原请求 ID 查询结果。上下文缺失时，用户可提供该 ID。查询沿用原期限。[D-063](../../decisions.md)

## 后续请求

同一 Session 内每笔交易各有原始字段、审阅链接和结果。用户在浏览器中核对并授权发送，agent 可按原 ID 查询或显式取消。收到哈希时展示「已发送」及哈希。结果未确定时保留查询入口，迟到哈希更新原请求。[交易规则](../03-single-transaction/spec.md) · [恢复验收](../04-collaboration-recovery/acceptance.md)

agent 可转述用户明确表达的交易目的。无法可靠说明 calldata 时可省略意图，审阅页显示「调用方未提供说明」并保留原始字段。[D-065](../../decisions.md)

等待审批或等待钱包返回时，agent 可间隔查询。若交易已交给钱包，取消操作返回服务记录的实际状态。收到「结果未确定」时，agent 结束本轮自动等待，告知用户交易可能已广播，提供原请求 ID 与查询入口。用户稍后继续时查询同一记录，禁止自动重发。[D-066](../../decisions.md)

## 连接来源与重试

审批页显示 MCP 客户端在握手时自报的标题，标题为空时使用名称。agent 在工具调用前为本次连接生成随机请求 ID。响应丢失或进程重启后，按原 ID 查询或携原内容重试。同 ID 改变内容返回冲突。用户主动发起另一份连接时使用新 ID。[D-064](../../decisions.md)
