# 迭代 7 · 第 1 轮体验反馈

原始现象、用户决定和已验证环境见[第 1 轮记录](../../local-trials/v0.1.0/round-01/feedback.md)。本轮按以下条件复测。

| 反馈 | 验收条件 |
|---|---|
| 1、2 · 交易 Session | `transaction send` 缺少 Session ID 或格式有误时，指出 `--session-id`、有效格式及取得 ID 的命令。保留退出码 2 和脚本可读的 JSON 错误。用户用有效 ID 复测后再讨论省略选项。 |
| 5 · CLI 自助使用 | 从顶层帮助找到命令用途，从子命令帮助识别参数含义、必填项和省略时的行为。典型错误指出失败原因与可执行的纠正步骤。 |
| 3、4 · Git Bash | 在新的 Windows Git Bash 终端按指南运行候选程序，定位 Codex CLI、完成 MCP 注册并核对路径。用户已确认以 Git Bash 实测验收。 |
| 6 · 审批链接 | 在 macOS Codex 中点击连接或交易的审批链接，在装有插件钱包的系统默认浏览器继续原请求。核对请求 ID、授权边界和审批次数。具体打开方式待宿主验证。 |
| 6 · 首次授权 | 先记录新用户需要离开 Codex 执行的步骤，再就改进方式确认需求。 |

本轮交付本地候选与按反馈编号组织的复测步骤。公开发行由用户体验后另行确认。
